# SuiteScript-2.1-Upgrade-Report-Toolkit
Free, open-source NetSuite Suitelet that lists every script not on SuiteScript 2.1, with its version, type, last execution and source (Bundle, SuiteApp or SuiteScript), so you can plan your upgrade. Writes nothing and makes no outbound calls; optional AI script summaries use NetSuite's built-in N/llm. MIT licensed.
